Problem Statement

Navigation-Error Recovery, Not Template Matching

Given a high-resolution reference (1000×1000, 1 nm/px, 100× zoom) and a wide-search image (1000×1000, ~10 nm/px, 10× zoom), locate the reference pattern's center to sub-pixel precision.

Key Reframing

The tool knows where it commanded the stage. Drift is a small, bounded error — not an arbitrary location in a 10 μm field. A recovery system exploits this prior, not just image content alone.

Phase 1 Constraints

  • Exact 10× zoom ratio (known)
  • No rotation
  • Reference always present

Phase 2 Extensions

  • Zoom unknown — uniform [8×, 12×]
  • Rotation unknown — ±5°
  • ~20% absent pairs (rejection required)
  • Degraded images (charging, defocus, noise)
  • 20s hard timeout, ≤5s median target

Synthetic Dataset Generator

Physically-Motivated SEM Image Synthesis

Structure Rendering

  • DRAM — word-line / bit-line / contact array
  • FinFET — parallel fin / gate-line array
  • RGB Optical — 3-channel diffraction + chromatic aberration

Same renderer at both scales — only pitch/width parameters change with zoom ratio.

Line-Edge Roughness (LER)

Smoothed random perturbation of each edge — not pixel-IID noise but spatially correlated, matching real lithographic processes. Makes neighbouring "identical" cells visually similar but not pixel-identical — the source of genuine periodic ambiguity.

SEM Noise Model (4 Components)

  • Shot Poisson noise — signal-dependent, dominant
  • Read Gaussian — additive, signal-independent
  • Blur Beam-spot PSF — Gaussian convolution
  • Jitter Per-row scan-line intensity offset

Search image deliberately noisier (lower gain, larger blur) — modeling fast survey scan vs. careful characterization.

Phase 2 Degradation Effects

  • Charging artifacts (localized bright blooming)
  • Scan distortion (smooth 2D displacement field)
  • Polygon CD jitter (±20% critical dimension)
  • Elevated shot noise + defocus

Prior-Window Innovation

The tool knows the commanded stage position. Drift is bounded (typically <60 px). Discarding candidates outside this window is simultaneously:

  • Faster — smaller effective search area
  • More robust — distant periodic decoys eliminated
  • Zero precision loss — same FFT-NCC + refinement inside window

Grounded in US Patent 7,545,497 — alignment routines for optically based tools.

Global Ambiguity Ratio (GAR)

A corrected confidence metric replacing local PSR. Compares best NCC peak vs. best non-local competing peak anywhere in the image (Lowe's ratio test style).

  • GAR ≈ 0.88–0.91 → easy (clear unique match)
  • GAR ≈ 0.98–0.999 → ambiguous (decoy present)

PSR only sees local sidelobes — wrong scope for distant periodic decoys.

True site scored 0.8464 vs decoy's 0.8438 — a 0.3% gap. Algorithm chose the decoy (closer to center, per spec tie-break rule).

Root cause: Purely image-based tie-break cannot resolve structurally identical periodic sites. This is the exact failure mode the prior-window mechanism resolves.

Phase 2 — Algorithm

Multi-Stage Beam Search over (Scale, θ, Position)

Stage 1 — Coarse Grid Sweep

9 scales × 5 θ anchors = 45 evaluations

Scale: {8.0, 8.5, 9.0, ..., 12.0} · θ: {-5, -2.5, 0, 2.5, 5}°

Each eval: cv2.matchTemplate(TM_CCOEFF_NORMED)

Output: Top-3 (scale, θ) by NCC score

Stage 2 — θ Refinement

Per beam candidate: sweep θ ±1.5° in 0.5° steps

Output: Top-3 after re-sort

Stage 3 — Fine Joint Refinement

Per beam candidate: scale ±0.3 (step 0.3) × θ ±0.6° (step 0.3°)

New Multi-peak extraction: Top-4 distinct spatial peaks per NCC surface (min_sep 15% of template size) — prevents aliased periodic lobe from silently winning.

Final Selection

All candidates scored by:

confidence = score × (1 − GAR)

Winner = highest confidence → subpixel parabolic refinement

Rejection Logic

found = (score ≥ 0.43) OR (gar ≤ 0.65)

Score carries primary separation weight. GAR rescues borderline-score present pairs with high spatial confidence (low ambiguity).

Calibrated on real 20-pair organizer sample set. F1 = 1.000.

Safety Budget

Wall-clock early-exit guard at 17.5s prevents hard-timeout kills. Median actual: 2.13s/pair.

Honest Assessment

Failure Modes, Limitations & Explainability

Failure Mode 1: Periodic-Array Ambiguity

Without prior window, structurally identical periodic sites produce NCC scores within 0.3% of each other. Image-content-only tie-break fails when two sites are genuinely, physically indistinguishable.

Resolution: Prior-window mechanism uses information outside the image alone (stage commanded position). 100% success with prior.

Failure Mode 2: Scale Quantization

At scale_step=1.0, true scale 10.55 falls 0.45 from nearest grid point. Degraded NCC quality at wrong scale lets unrelated structural matches win outright — confident wrong positions at 81–226 px error.

Resolution: scale_step=0.5 ensures ≤0.25 from true scale. All sub-1px after fix.

Failure Mode 3: FFT-NCC Implementation Bug

Hand-rolled integral-image + FFT correlation had a subtle bug — returned wrong location at 18–358 px error while reporting high confidence scores (0.66–0.82). The algorithm appeared to work but silently produced incorrect results.

Resolution: Replaced with cv2.matchTemplate — the single biggest accuracy fix. 0.3–0.7 px after fix.

Known Remaining Limitations

  • Borderline score gap (0.0001) between hardest present/absent pair — may produce edge cases on full 200-pair test set
  • RGB handled as grayscale conversion — no color-specific matching
  • Efficiency depends on other teams for quartile ranking
  • Local calibration data doesn't fully match organizer background diversity
